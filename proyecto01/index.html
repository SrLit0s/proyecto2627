Guía de Instalación y Configuración del Sitio Web Local

Esta documentación detalla los pasos seguidos para preparar el entorno de desarrollo local, clonar el repositorio del proyecto "misitio" y servirlo mediante Laravel Herd en HTTPS.

1. Requisitos Previos e Instalación de Herramientas

1.1 Git

Se ha procedido con la instalación y configuración global de Git para la gestión de versiones del proyecto.

git config --global user.name "Tu Nombre"
git config --global user.email "tu@email.com"

Figura 1: Confirmación de Git instalado y sus variables de configuración local.

1.2 GitHub CLI (gh)

Para facilitar la interacción y autenticación directa con GitHub desde la línea de comandos, se instaló GitHub CLI y se verificó el estado de la sesión.

gh auth status

Figura 2: Salida del comando gh auth status confirmando la sesión activa en GitHub.

1.3 Laravel Herd (PHP 8.4)

Se instaló Laravel Herd como entorno de desarrollo local, configurando y seleccionando la versión global de PHP en 8.4.

Figura 3: Panel de control o terminal mostrando Laravel Herd ejecutando PHP 8.4.

2. Clonación del Repositorio Local

Se procedió a clonar el repositorio "misitio" desde GitHub a la máquina local dentro del directorio de trabajo correspondiente.

gh repo clone tu-usuario/misitio
# O alternativamente:
# git clone https://github.com/tu-usuario/misitio.git

Figura 4: Estructura de archivos y terminal confirmando el repositorio clonado.

3. Configuración del Dominio Local y HTTPS con Herd

Para servir el sitio web localmente a través de un dominio .test con certificado de seguridad SSL (HTTPS), se enlazó el directorio del repositorio en Herd.

cd misitio
herd link
herd secure

Figura 5: Sitio web respondiendo en el navegador mediante HTTPS (https://misitio.test).

4. Resumen de Elementos y Plugins de ProperDocs (Tema Read the Docs)

En esta sección se resumen la estructura de archivos, comandos y elementos clave utilizados para generar esta documentación mediante ProperDocs:

4.1 Estructura del Proyecto y Archivo de Configuración

  • properdocs.yml: Archivo principal de configuración de ProperDocs situado en la raíz. Define los metadatos del sitio (título, descripción, autor), el tema visual y el árbol de navegación (nav).
  • Directorio docs/: Carpeta donde residen todos los archivos fuente en Markdown (.md) e imágenes (docs/img/).
  • Directorio site/: Carpeta de salida generada automáticamente tras la compilación que contiene el sitio HTML estático listo para ser servido (ficheros index.html, css/, js/, search/, sitemap.xml).

4.2 Comandos Clave de ProperDocs

  • properdocs new [dir]: Inicializa un nuevo proyecto con la estructura base de documentación.
  • properdocs serve: Inicia un servidor local con recarga en vivo (live-reloading) para previsualizar los cambios en tiempo real.
  • properdocs build: Compila los archivos .md de docs/ y genera el sitio estático HTML final en la carpeta site/.

4.3 Elementos del Tema readthedocs y Plugins

  1. Tema readthedocs:
  2. Proporciona la interfaz clásica de Read the Docs con barra lateral desplegable a la izquierda.
  3. Tabla de contenidos integrada (ToC) por página.

  4. Tipografía clara optimizada para lectura técnica y diseño responsivo.

  5. Buscador Integrado (search):

  6. Plugin nativo habilitado en properdocs.yml que indexa automáticamente todo el texto de los archivos Markdown para ofrecer búsquedas dinámicas sin necesidad de base de datos.

  7. Extensiones de Formato (Markdown Extensions):

  8. Bloques de código con resaltado sintáctico (pymdownx.highlight, superfences): Para la correcta visualización de comandos en consola (bash, shell).
  9. Notas y Avisos (Admonitions): Bloques destacados para resaltar información o advertencias sobre el proceso de instalación.
